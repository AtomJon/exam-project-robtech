# MazeSolver
This is a solution for the 2026 Robot Programming course exam on AAU.
It's intended for a Pololu Zumo 32UA configured with all linesensors.
It works by first finding the maze, here it should be placed facing an outside wall. Thereafter hugging a left wall until it finds the exit. There is no exit-condition, so it will run continously.
